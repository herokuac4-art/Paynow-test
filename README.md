# Pay Now — Payment Orchestrator & Link Builder (MVP)

A premium, developer-friendly SaaS that lets merchants connect payment gateways and
create hosted payment links in seconds.

> **Pay Now is a payment orchestrator / SaaS tool — not a Payment Aggregator.**
> It does not hold, transfer, or settle funds. All transactions are processed directly
> by the connected gateway (e.g. Razorpay, Paytm) and settled into the merchant's
> registered bank account.

## Run

```bash
npm install
npm start
# → http://localhost:3000
